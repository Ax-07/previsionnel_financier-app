# Dashboard KPI

## Description

Ce tableau de bord présente une vue d'ensemble des indicateurs clés de performance (KPI) du prévisionnel, permettant d'évaluer la santé financière et opérationnelle de l'entreprise. Il est organisé en plusieurs sections thématiques pour faciliter l'analyse.

## Sections

1. **Synthèse financière** : Présente les principaux KPI financiers tels que le chiffre d'affaires, les charges, et le résultat net, avec des graphiques comparatifs.
2. **Robustesse du modèle** : Évalue la solidité du prévisionnel à travers des KPIs secondaires et un graphique de seuil de rentabilité.
3. **Investissements & Financement** : Analyse les investissements prévus et les sources de financement, avec des KPIs dédiés et un plan de financement visuel.
4. **Tableau mensuel** : Offre une vue détaillée des performances mois par mois, permettant d'identifier les tendances saisonnières et les écarts par rapport aux prévisions.
5. **Analyse de sensibilité** : Permet d'explorer différents scénarios en ajustant les hypothèses clés du modèle, pour comprendre l'impact sur les résultats financiers.
6. **Comparaison avec les années précédentes** : Compare les prévisions actuelles avec les données historiques pour évaluer la croissance et les écarts.
7. **Alertes et recommandations** : Met en évidence les points d'attention et propose des recommandations basées sur les KPI analysés.
8. **Personnalisation du tableau de bord** : Permet à l'utilisateur de choisir les KPI à afficher et de configurer les graphiques selon ses besoins spécifiques.
9. **Exportation des données** : Offre la possibilité d'exporter les KPI et les graphiques pour les partager ou les intégrer dans des rapports externes.
10. **Mises à jour en temps réel** : Intègre les dernières données disponibles pour assurer que le tableau de bord reflète toujours la situation actuelle de l'entreprise.
